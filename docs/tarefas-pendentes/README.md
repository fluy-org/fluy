# Tarefas pendentes

Melhorias técnicas identificadas durante uma fatia, mas fora do escopo dela.
Cada tarefa tem um arquivo próprio com o problema, onde ele aparece e a
proposta. Ao concluir uma tarefa, remova o arquivo e a linha abaixo no mesmo PR.

Decisões de negócio adiadas não entram aqui: elas vivem em
[`flows/PENDENCIAS.md`](../flows/PENDENCIAS.md).
